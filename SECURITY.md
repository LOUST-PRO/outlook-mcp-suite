# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

Email **opensource@loust.pro** with:

- A clear description of the issue
- Reproduction steps (preferably a minimal example)
- Expected vs. actual behavior
- Impact assessment (data exposure, auth bypass, RCE, etc.)

We aim to acknowledge within 72 hours. Please **do not** open a public
GitHub issue for suspected vulnerabilities.
